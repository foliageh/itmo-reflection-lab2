# Решение: генератор объектов на Java Reflection

## API

```java
Generator gen = new Generator();                         // new Random()
Generator gen = new Generator(new Random(42));           // воспроизводимая генерация
Generator gen = new Generator(random, 3, "org.my.impl"); // глубина вложенности + доп. пакеты для поиска реализаций

Rectangle r = gen.generateValueOfType(Rectangle.class);  // <T> T generateValueOfType(Class<T>)
Object o = gen.generateValueOfType(field.getGenericType()); // Object generateValueOfType(Type), например List<Integer>
```

При ошибке генерации возвращается `GenerationException` (unchecked) с описанием причины.

## Архитектура

- `Generator` — рекурсивная функция `generate(Type)`. Ветка выбирается по категории типа: примитив/обёртка → `String` → enum → массив → `Collection` → `Map` → интерфейс/абстрактный класс → пользовательский класс. Работа идёт с `java.lang.reflect.Type`, поэтому generic-параметры (`List<Product>` в конструкторе `Cart`) берутся из `Parameter.getParameterizedType()`.
- `ImplementationScanner` — ищет на classpath (каталоги и jar) реализации интерфейсов и абстрактных классов, результат кэшируется.
- Аннотации: `@Generatable`, `@Range`, `@Invariant`.

## Семантика `@Generatable`

Разрешает генератору создавать объекты этого класса или использовать помеченный конструктор.

- <b>Если аннотация висит на классе:</b>  
    Генератор понимает, что этот класс разрешено создавать. Если попытаться сгенерировать класс
    без этой аннотации, программа упадет с ошибкой `GenerationException`.
- <b>Если аннотация висит на конструкторе (или нескольких):</b>  
    Генератор будет создавать объект строго через эти помеченные конструкторы (в том числе приватные).
    Если на конструкторах аннотации нет, генератор возьмет любой публичный конструктор.
- <b>Если мы запрашиваем генерацию интерфейса или абстрактного класса:</b>  
    Сам интерфейс пометить нельзя. Генератор будет искать среди всех доступных классов-реализаций только те,
    на которых висит аннотация `@Generatable`, и выберет одну из них для создания объекта.

Встроенные категории (примитивы, `String`, enum, массивы, коллекции) аннотации не требуют.

## Поддерживаемые типы и параметры генерации

| Тип | Как генерируется                                                                                                                   |
| --- |------------------------------------------------------------------------------------------------------------------------------------|
| целые / `double` / `float` | равномерно в `[-1000, 1000]` (или в `@Range`)                                                                                      |
| `boolean`, `char` | случайный / буква или цифра                                                                                                        |
| `String` | 1–10 символов `[a-zA-Z0-9]`                                                                                                        |
| enum | случайная константа                                                                                                                |
| массивы (в т.ч. `T[]`, многомерные) | длина 1–5                                                                                                                          |
| Коллекции (List, Set, Queue, Map) | реализации по умолчанию (`ArrayList`, `HashSet`, `LinkedList`, `HashMap`), cоздаются через пустой конструктор, от 1 до 5 элементов |
| пользовательские классы и records | через конструктор, аргументы генерируются рекурсивно                                                                               |

Generic-аргументы: для raw-типов (`List.class`), `?` и `T` без границ используется `String`, для `? extends X` — `X`.

## Ограничения

- Объекты создаются только через конструкторы. Поля и сеттеры не заполняются.
- Рекурсивные структуры (`BinaryTreeNode`) ограничены глубиной `maxDepth` (по умолчанию 4). На пределе ссылки на пользовательские объекты равны `null`.
- Коллекции и массивы пустые.
- Реализации ищутся только в указанных пакетах. Нестатические внутренние, локальные и анонимные классы не поддерживаются.
- Интерфейсы `SortedSet`/`SortedMap` не поддерживаются.
- У пользовательских generic-классов `T` из контекста не выводится: вместо `T` подставляется его граница.

## Доп. задание: предметные ограничения

- `@Range(min, max)` на параметре конструктора задаёт диапазон числа (`Rectangle`: стороны в `[0.1, 100]`, `Product.price > 0`).
- `@Invariant` на методе типа boolean без аргументов проверяет созданный объект. Если проверка не прошла, генератор создаёт объект заново (до 100 попыток).
- Если конструктор бросил исключение (например, `IllegalArgumentException`), это тоже повод для новой попытки. После 100 неудач выбрасывается `GenerationException` с причиной.
